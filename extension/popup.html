Auto-fill email codes

Reads subject lines from open Gmail or Outlook tabs to detect one-time codes. Nothing is stored or sent — the code is read locally and discarded after use.

Backup & Restore
An encrypted file with everything in your vault — passwords, 2FA codes, notes, custom fields, every item type. Import it in another browser to move or copy your vault.

The CSV holds every password, 2FA secret and note in plain text: anyone who opens the file can read them. Use it to move to another manager, then delete it.

It includes your crypto wallets' recovery phrases and private keys: whoever gets the file can take the funds.

Import from Google Authenticator

In Google Authenticator: ⋮ menu → Transfer accounts → Export accounts → select accounts. Screenshot each QR code shown (there may be more than one if you have many accounts), then select those screenshots below. This only copies your accounts — nothing is removed from Google Authenticator.

Import from a password manager

Export your passwords as a CSV file from Chrome, Edge, Brave, Firefox, Bitwarden, 1Password, LastPass, Dashlane or KeePass, then select it here. Passwords for sites you already have a 2FA code for are added to that login. Delete the CSV afterwards: it isn't encrypted.
